# WakeelAI-Frontend

## Deployment

Production: [https://wakeel-ai-frontend.vercel.app](https://wakeel-ai-frontend.vercel.app)

Deployed on Vercel. `VITE_API_BASE_URL` is set to `https://wakeel-ai-api.runasp.net` (the backend's origin, no trailing slash, no `/api` suffix) via the project's Vercel environment variables.
